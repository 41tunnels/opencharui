# Contributing

Thanks for taking the time to contribute.

## Signing the CLA

Before we can accept a pull request, you need to agree to a Contributor
License Agreement (CLA). It lets you keep your copyright while granting
41tunnels the rights needed to distribute the project — including under a
different license in the future, such as a commercial offering alongside
the existing AGPL-3.0-or-later license.

- If you're contributing as an individual, read the [Individual CLA](CLA.md).
- If you're contributing on behalf of an employer or other organization,
  read the [Entity CLA](CLA-entity.md) instead.

You only need to sign once — it covers all 41tunnels projects (Amallo,
Relay, OpenCharUI).

To sign, add the following to your first pull request's description
(the PR template includes a checkbox for this):

> I have read and agree to the [41tunnels Individual CLA](CLA.md).

or, if signing as an entity:

> I have read and agree to the [41tunnels Entity CLA](CLA-entity.md) on
> behalf of `<organization name>`.

If you have questions about the CLA, reach out to hello@41tunnels.com
before opening a PR.

## Making a change

- Open an issue first for anything beyond a small fix, so we can agree on
  the approach before you put time into it.
- Keep pull requests focused — one change per PR is easier to review.
- Follow the existing code style in the file you're editing.
